## 已完成的蓝图调整

原图库 135 张、5,588 个非空气方块，无重复坐标或越界坐标。本次修改 27 张，移除 1,201 个装饰性铺底方块，现为 4,387 个方块；26 张降低星级，熊猫保持 3 星。未修改其余 108 张。

不是按“最低层”批量删除：时钟表盘、苦力怕等平面图案、船底、篮底、小神社台基、观星台/樱花亭框架、音符盒外壳与魔法书封面均属于主体，保留。迪厅彩色舞池属于主题主体，保留；火车进站只删除外围碎石，保留站台、安全线和轨道垫木；海底神殿保留海晶石台基，去除外围沙地并使独立矮柱落地；熊猫只删苔藓底板。

整片底板删除后通常把主体下降一格。仙人掌、蘑菇、花草保留必需的独立基质；自然餐桌的杜鹃组成桌体，因此保留基质和椅脚支承，保持桌椅相对高度。海底神殿矮柱下移后，已将 9 个围墙的连接状态同步为新邻接关系，避免自然搭建后状态不匹配。

## 完成判定结论

- 坐标口径一致：`ReferenceBuilder.paste` 与 `submitSlot`/`scoreIncomplete` 都使用地板最小角加 Y=1 的原点；建造权限、清理范围均是其上方 7×7×7。未发现整体偏一格、负坐标截断或普通/黄金原点不一致。
- 玩家点击提交后比较蓝图文件中保存的 BlockData，而非读取现场展示建筑。成功与期末部分得分共用相同匹配函数。
- 多余方块被忽略是现有明确规则，不能把“蓝图所有目标格正确”理解成“整个体积与蓝图完全一致”。此次未改变这一规则。
- 已删除遮挡替代：泥土不能代替草方块，下界岩不能代替任一种菌岩，不再读取玩家上方的遮挡方块。原本“添加额外遮挡以绕过材料要求”的路径已移除。每个目标方块也减少一次世界方块读取。

## 检查发现的问题及最终修复

| 问题 | 修复 |
| --- | --- |
| 比赛结束与黄金轮换同 tick，轮换先清空末轮建筑，损失部分分数 | 删除独立轮换定时任务，由同一比赛倒计时驱动。剩余 0 秒不再轮换，直接保留当前建筑进行终局结算；末轮倒计时不会超过比赛剩余时间。重置同时取消比赛时钟。 |
| 黄金首次确认可跨轮用于新订单；副手事件可能触发第二次确认 | 只处理主手提交，双手事件均取消原生按钮动作。确认绑定玩家、队伍、槽位、订单代次，使用单调时钟；轮换、结束、重置和退出清理。无有效订单或最后 10 秒不进入确认。 |
| 展示区只按已有方块保护挖掘，工具及共享黄金展示交互漏保护 | 普通/黄金展示均按完整 7×7×7 体积和底部地面保护；覆盖双手交互、放置/破坏、桶、流体、活塞、物理、生长、衰变、火、实体改块、红石和爆炸方块列表。保护在倒计时/比赛中启用，按世界与地图范围隔离。 |
| 流体/活塞可跨建筑边界；材料区判断缺世界过滤 | 流体与活塞只能在同一建筑体积或同一材料区内转移。允许材料区正常工具使用和本队区内建筑操作；材料区查询复核世界。活塞回拉按活塞真实朝向的反方向计算移动，不误禁边缘向内回拉。 |
| 门/床等只校验主方块 | 遍历 `BlockMultiPlaceEvent.getReplacedBlockStates()`，全部受影响格必须在本队建筑体积内，且不得触及展示。 |
| 坏蓝图行被静默跳过，分母变小 | YAML 解析失败、非列表、非字符串条目、无效 BlockData、空蓝图、重复/越界坐标整张拒绝。日志提供文件名与列表项编号（YAML 语法错误保留解析器行列信息）。导出时增加现场支撑检查；不在加载时修改世界。 |
| 普通提交失败只有匹配数量，难定位 | 一次 O(N) 扫描同时给出匹配、缺失、材质错误、状态错误数量与最多三个相对坐标。保留旧自定义完成度消息，message v56 新增单独差异提示。 |
| 普通方块也反复序列化铜状态 | 非蜡铜材质直接返回；蓝图构造时缓存规范化参考状态，提交/终局仍以真实世界扫描为准。 |
| 运行规则说越早完成每星分越高，与实际相反 | 修正为 0–4 分钟每星 10 分、4–8 分钟 15 分、8 分钟后 20 分，与默认配置/实现一致。 |

原终局时序问题曾在隔离 Paper 缩时复现为 `rotate@2,4,6,8,10,12` 后才 `end@12`。新回归覆盖 720/120 秒配置，只允许剩余 600/480/360/240/120 秒轮换；也覆盖不整除周期、重复 tick、比赛短于轮换周期及到零边界。

### 树叶距离已验证并修复

此前普通短时间邻居事件探针仍为 52/52，不能据此证明叶距不会变化。此次在同版本隔离 Paper 直接调用原版 `LeavesBlock.updateDistance`，樱花亭四片树叶均从保存的 `distance=7` 计算为 `1`；旧严格比较全部不匹配。新规则仅忽略不可见的叶距，保留种类、persistent、waterlogged，应用自然叶距后的整座蓝图仍为 52/52。

这是原版叶距计算的隔离验证，尚未进行真人生存摆放流程验收。其他连接、门、围墙、楼梯与半砖状态继续遵循既有规则；额外方块仍忽略。
