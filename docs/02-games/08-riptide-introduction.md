# Riptide 规则体验场地

正式赛事第一轮使用固定教学世界 `riptide_introduction`，全部 Riptide 地图共用。规则介绍仍为 90 秒，完整规则与积分说明在进入教学世界前播报。练习不计分、不淘汰，失误救回当前木筏；正式比赛的关卡组合、数量与难度仍由所选地图决定。

## 教学航线

场景采用正式地图的海面、条纹帆棚营地、棕榈岛、航标和救援港。移动木筏为 7×9 橡木甲板，海面在甲板下两格，离开的甲板位置恢复为空气。两面穿越墙直接使用正式 HITW 池的“冰场 D06”和“高楼 E06”建筑快照；红蓝答题门、金色挑战入口、铁质节奏门与绿色终点标记均由正式生成器构建。路侧说明牌不覆盖洞口。

| 时间（约） | 体验 |
| --- | --- |
| 0–4 秒 | 起航营地集合，四秒出发倒数，介绍跟筏闯关的目标 |
| 4–8.5 秒 | 自行跟随木筏，熟悉脚下安全范围 |
| 8.5–20 秒 | 两面正式建筑临近显现，看洞口换位穿过 |
| 20–28.4 秒 | 行进中读题，从左红或右蓝的正确答案门通过 |
| 28.4–55.9 秒 | 独立踩色停泊点，完整七次判断，然后等待两秒 |
| 55.9–64 秒 | 重新航行至下一处挑战入口 |
| 64–75 秒 | 独立躲避停泊点，完整九秒冲刺挑战，然后等待两秒 |
| 75–77.2 秒 | 恢复航行，提醒后段加速与即将到来的节奏门 |
| 77.2–84 秒 | 看红绿灯、听音符，穿过动态节奏门；木筏不停 |
| 84–90 秒 | 抵达救援港，等待介绍结束，随后进入原准备流程 |

时序由 140 格实际航程、正式默认船速和机制耗时推导。船速在 20%、40%、60%、80% 航程依次从 2.2 提升至 2.95、3.7、4.45、5.2 格/秒；40% 时剩余护盾破碎，80% 时提供速度 I。踩色采用所在航段的正式七轮时长与材料数量，躲避采用所在航段的正式刷新参数。停船和两秒等待期间不前进，继续判断掉落。

教学是一组固定示例，不覆盖全部正式关卡变体。它使用正式建筑与机制，缩短航程并固定题目种子；答题操作数为 10–20。完整关卡变体见 [关卡与编排](06-riptide-stage-mechanics.md)。

## 提示、救回与生命周期

玩家文案只介绍规则和当前操作，不说明教学与正式赛的设置差异。每段开始时在聊天说明操作；随筏引导牌显示当前阶段和一句提示。数学题、踩色倒数、目标方块、躲避来向、剩余时间和出发等待使用正式呈现。护盾破碎提示不覆盖答题标题。通过终点入口，或木筏停靠时仍在甲板上的玩家，不再接受离筏检查，可以在终点自由走动；判定按玩家独立保存，并随本次活动清理。

掉落沿用正式逐 tick 支撑检测和 20 tick 确认，踩色允许正常跳跃。首次失误在护盾有效期间消耗护盾，后续失误仍教学救回。救回选择甲板上的可站立位置，避开墙体；踩色优先落在目标材料上。答错后使用正式数学恢复入口，避免传送重复提交答案。

参赛者使用 Adventure，真实旁观者继续走统一旁观服务，不参与答题、踩色、躲避或节奏碰撞。正常选手沿用同队显隐与完整 Tab。重连回到当前木筏，补发当前踩色提示物和末段速度效果，不补发护盾。结束、取消、中止、reset、重载和卸载释放任务，恢复显现遮挡与节奏门，清除冲刺实体、临时文字和速度效果，恢复起点木筏并释放教学所有权。正式赛道与其发布状态不受教学建筑生成影响。

## 编辑与版本迁移

重启 Core 后自动加载教学世界、预热区块并分批生成。管理员进入任意 Riptide 地图编辑，在准备步骤选择“规则介绍试玩场地”即可查看；机制在正式首轮介绍期间运行。配置为 `plugins/ChampionshipsCore/riptiderush/introduction/arena.yml`，`enabled: false` 使用原规则介绍，原地图介绍点继续作为教学不可用及正式赛道生成期间的等待点。

教学世界空闲时固定为晴天正午（6000 tick），每次开始介绍时同步所选正式地图的时间并关闭时间流逝。调整光照不触发建筑重建。

`spawn` 默认 `(0.5, 80, 0.5)`，路线向 +Z 延伸，世界名固定。蓝图版本为 **3**。旧版本会清空教学占地并重新生成：前后 −16 至 154 格、左右 ±24 格、相对甲板高度 −5 至 12 格。此次升级会替换旧水渠内的装饰；正式比赛地图不变。成功生成并保存世界后才写入 `prototype-version`。当前版本的路外精修在后续加载时保留；只有需要整体重建时才将版本改为 0。

移动带（前后 −4 至 144、横向 ±3、甲板层）和六个关卡的建筑体积（各关卡前后边界内、横向 ±7、甲板上 1–12 格）由机制占用，每次加载恢复，清理意外停机保存的甲板、遮挡或关闭的节奏门。请在这些区域之外施工。终点甲板前沿为 144 格，救援港从 145 格开始衔接。

## 开发与验证

`BaseGameInstance` 拥有介绍计时、重连、复活与取消流程。`RiptideIntroductionArena` 拥有教学世界与区块租约；`RiptideIntroductionLesson` 保存固定关卡计划及按正式默认速度、停顿时长推导的航程；`RiptideIntroductionRun` 使用正式生成器、显现、木筏、数学、踩色、躲避和节奏实现，逐 tick 检查连接、场地与统一资格。

测试位于对应模块的 `src/test/java`，覆盖全程时序、完整七轮及两秒等待、五档船速、正式建筑来源、答题反应距离、完整净空和文案。原生验证覆盖建筑粘贴、遮挡恢复、完整航程、挑战结束及取消后的恢复。隔离验证不替代真人客户端的视觉和移动手感验收。

仅 Core 实现 Riptide；Bingo Worker 无此教学流程，共享协议、Tab、旁观和显隐实现未修改，无须部署 Worker。
