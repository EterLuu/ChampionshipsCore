# Riptide 规则体验场地

正式赛事的第一轮规则介绍使用固定教学世界 `riptide_introduction`，全部 Riptide 地图共用。介绍仍为 90 秒；完整规则及积分说明在玩家进入教学场地前于大厅播报，教学期间只在聊天和文字展示实体中提供练习说明。原地图的介绍点作为教学场地不可用时的回退及首轮正式赛道生成期间的等待点。

| 时间 | 体验 |
| --- | --- |
| 0–10 秒 | 在木筏上集合，了解练习救回与一次性护盾 |
| 10–26 秒 | 自己向前跑，跟随 2.2 格/秒的木筏，通过中央洞口 |
| 26–42 秒 | 提前换位，通过侧面洞口 |
| 42–62 秒 | 木筏停下，按提示踩中目标方块，七次判断逐步加快 |
| 62–73 秒 | 体验正式玩法的九秒冲刺生物躲避，随后短暂停顿 |
| 73–86 秒 | 护盾全部破碎，木筏加速至 5.2 格/秒 |
| 86–90 秒 | 到达终点，随后进入原正式准备与倒计时 |

练习不计分、不淘汰。离筏、踩错和碰撞均给出提示并救回；首次失误消耗护盾，后续允许继续练习。掉落沿用正式玩法的逐 tick 支撑判断与 20 tick 确认，踩色允许正常跳跃。救回选择当前木筏上的可站立位置，避开墙体；踩色时优先选择目标方块。踩色标题与目标方块 actionbar、躲避来向及剩余时间、护盾破碎和加速提示与正式玩法共用文案和呈现逻辑；教学说明不占用这些位置。首版体验穿越、踩色与躲避，解题、节奏等机制由大厅规则播报介绍。

参赛者使用 Adventure，自行跟随木筏；真实旁观者继续使用统一旁观服务，不参加任何机制。保留 Riptide 正常选手的同队显隐策略与原 Tab 契约。重连和复活恢复到当前练习木筏，不补发已消耗的护盾。完成、取消、中止、reset、热重载和卸载取消体验任务、清除冲刺实体及临时目标展示、恢复初始木筏并释放所有权；正式开始前清空练习状态。

## 查看与精修

重启 `cc-core` 后自动创建世界、预热区块并分批生成原型。管理员进入任意 Riptide 地图的 map edit 后，在“准备步骤”中点击“规则介绍试玩场地”即可传送到共享教学世界；编辑完成后返回地图世界，再保存草稿、发布或退出地图编辑。世界出生点位于后方安全栈道。交互机制在正式赛事第一轮介绍期间运行。`/cc admin world teleport riptide_introduction` 仍可作为只读查看的备用入口。

配置位于 `plugins/ChampionshipsCore/riptiderush/introduction/arena.yml`。`enabled: false` 恢复原规则介绍。`spawn` 定义教学木筏起点，默认 `(0.5, 80, 0.5)`，路线向 Z 正方向延伸；教学世界名称固定，避免将生成器指向大厅或正式地图。配置变更通过重启加载。

水渠为青色混凝土和浅蓝水池，两侧设木质观景栈道、玻璃护栏和海晶灯拱架。初始木筏为正式默认的 7×9。文字展示位于甲板以上约 1.45 格的视线高度，沿航线侧面布置。原型只在 `prototype-built: false` 时生成，成功保存世界后记录 `true`。之后可以精修水池、栈道、拱架与墙体；每次加载保留这些建筑。

起点前四格至终点后四格、横向 ±3 格、Y=79 的甲板带由机制占用，每次加载清空并恢复起点木筏，以恢复意外停机留下的移动木筏或踩色地板。不要在该甲板带施工；墙体洞口需保留玩家通行空间。只有明确需要重新生成全部原型时，才将 `prototype-built` 改为 `false`。原型生成不改正式比赛世界、地图坐标、关卡池或发布状态。

## 开发与验证

`BaseGameInstance` 继续拥有 90 秒计时、重连/复活和取消流程，通过活动生命周期回调接入 Riptide；教学活动开启时跳过重复规则和通用介绍标题，其他游戏沿用默认规则播报。`RiptideIntroductionArena` 拥有教学世界与区块租约，由 Riptide Manager 释放；`RiptideIntroductionRun` 使用既有木筏、掉落、踩色和冲刺实现，逐 tick 核对当前连接、场地归属和统一游戏资格，不另存旁观身份。

纯时间与原型几何测试位于 `src/test/java/.../riptiderush/runtime/`。隔离原生验证应覆盖完整 90 秒、错误救回、护盾消耗及加速破碎、旁观资格、正常结束、取消、重载建筑保留及旧任务失效。隔离连接和探针不替代生产中真实客户端的移动手感验收。

只修改 Core；Bingo Worker 不实现 Riptide，共享规则时间线、模式呈现、Tab 和旁观实现未改，无须部署 Worker。
