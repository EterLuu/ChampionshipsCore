# HITW 建筑目录

激流勇进从插件内的 `riptiderush/hitw-walls.json` 读取内置目录，默认地图的 `course.pool` 保存建筑快照。运行时不访问 Wiki，不自动迁移旧快照，也不覆盖管理员保存的建筑。关卡编排和地图调整见 [Riptide 指南](riptide-stage-mechanics.md)。

## 来源与适配

内置 [目录资源](../championships-core/src/main/resources/riptiderush/hitw-walls.json) 为 v4，来源于 [MCC Island Wiki 的 Hole in the Wall 页面](https://mccisland.wiki/Hole_in_the_Wall) 修订 32764，包含 13 个子地图的 354 条来源记录。来源 E/D/X 标签标识来源分组，目录的难度值按有效通行截面积评级。

内置建筑快照宽 15 格、高 5 格，包含完整 BlockData 与通行元数据。管理员自建建筑按编辑器尺寸校验，不受该内置尺寸描述约束。保存尺寸、木筏内的可通行区域和实体碰撞空间分别处理，不能用建筑外框宽度代替可通行面积。

生产资源位于 `championships-core/src/main/resources/riptiderush/`。管理员通过地图编辑器修改建筑并重新校验、发布；修改资源时同时核对目录与默认地图的对应建筑。

## 通行与难度

内置目录的评级口径是在七格甲板范围、脚面以上三格内计算有效通行截面积。洞宽至少 0.6 格；平地或半格台阶可使用 1.5 格潜行洞，一格门槛需要至少 1.8 格净高。高窗和窄缝不计入，重叠洞口去重，厚建筑取各非空墙面的最小值。

| 通行面积 | 难度 |
| --- | --- |
| 至少 6 格² | 1 |
| 至少 3 格²、少于 6 格² | 2 |
| 少于 3 格² | 3 |

运行时读取关卡池保存的 `difficulty`（1–3），编辑器允许管理员调整；保存建筑不会自动重新计算难度。修改后的建筑需要重新评估难度并试玩。

连续墙还需检查换位和动作时间。只有快照完全匹配目录的建筑才使用目录通行元数据，改过的建筑不能沿用原图洞口判断；未知洞口的自建建筑仅单独出现。

## 验证

目录与默认资源的自动回归从仓库根目录执行：

```bash
mvn -B -ntp -pl championships-core -am test
```

在支持的 Paper 上逐关试玩，检查半砖、楼梯、潜行洞、门槛、左右镜像及连续换位，再验证完整赛道。资源解析和尺寸评级不替代原生碰撞与实际游玩验收。
